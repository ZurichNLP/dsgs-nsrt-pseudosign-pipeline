# hamparse (original)

HamNoSys parser module written by Prof. Sarah Ebling, shared on 2026-10-08.

Parses a HamNoSys string into its four phonological parameters:
- HS (handform / handshape)
- HP (handposition)
- LOC (location)
- MOV (movement)
